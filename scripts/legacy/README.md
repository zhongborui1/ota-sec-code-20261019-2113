# Legacy 脚本目录

本目录保存**已被取代**的历史脚本，保留用于：
1. 对比新旧实现（演进过程）
2. 审计历史测试记录
3. 教学/答辩参考

**不参与正式验收**。

## 文件清单

| 文件 | 原用途 | 被谁取代 | 备注 |
|:---|:---|:---|:---|
| `03-security-tests-legacy.sh` | 早期手工安全测试（5 次单点） | `08-negative-tests.py`（7 类 × 100 次） | 输出不含批量拒绝率统计 |
| `05-key-rotation-test.sh` | 早期密钥轮换测试 | `06-rotation-measure.py`（含宽限期验证） | 无 deprecated 状态 |

## 注意事项

- 这些脚本里的口令仍为早期的 `v1pass` / `v2pass`，**无法运行**（当前密钥已改用 32 字符强口令）
- 如需运行请参考新脚本的 `.secrets` 读口令方式
